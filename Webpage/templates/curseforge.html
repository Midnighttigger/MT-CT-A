    The Goal of this Resourcepack is to mostly add addons and compatability with other packs to MT-CT-D and MT-BGS.
    Please load with Addon Pack on top, one of my base packs in the middle and the base texture pack (such as Faithful) on the bottom

Addons?

  • CG - Clear Glass, available with clear 'Tinted' too
  • PA - Programmer Art, 'Jappa' is for adding modern textures to 1.12
  • F32x - Compatability pack addon for Faithful32x
  • F64x - Compatability pack addon for Faithful64x
  • BB - Compatability pack addon for Bare Bones; this is also good to have with Bare Bones 26.1+

FAQ

  • Make sure to have the loading order as shown here/the gallery. (Addons load after)
  • No connected textures? -> look at the top of the modpage!
  • "made for an older version of Minecraft" -> just load the pack as normal and it should run fine unless mojang has made significant changes to their resourcepack format
  • Make sure you have the correct version for your version and compatible base pack
  • Breaks with sodium pre 0.6.0 without indium, this is mostly because sodium (not embeddium) changes the fabric rendering system so indium fixes that
