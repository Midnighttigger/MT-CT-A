<ul>The Goal of this Resourcepack is to mostly add addons and compatability with other packs to <a href="https://modrinth.com/resourcepack/mt-ct-d">MT-CT-D</a> and <a href="https://modrinth.com/resourcepack/mt-bgs">MT-BGS</a>.<br>
Please load with Addon Pack on top, one of my base packs in the middle and the base texture pack (such as Faithful) on the bottom<br></ul>

<center><h2>Addons?</h2></center>
<ul>
<li>CG - Clear Glass, available with clear 'Tinted' too</li>
<li>PA - Programmer Art, 'Jappa' is for adding modern textures to 1.12</li>
<li>F32x - Compatability pack addon for <a href="https://modrinth.com/resourcepack/faithful-32x">Faithful32x</a></li>
<li>F64x - Compatability pack addon for <a href="https://modrinth.com/resourcepack/faithful-64x">Faithful64x</a></li>
<li>BB - Compatability pack addon for <a href="https://modrinth.com/resourcepack/bare-bones">Bare Bones</a>; <a href="https://modrinth.com/resourcepack/bare-bones-tiny-drops">this</a> is also good to have with Bare Bones 26.1+</li>
</ul>

<center><h2>FAQ</h2></center>
<ul>
<li>Make sure to have the loading order as shown <a href="https://cdn.modrinth.com/data/nVen30Ks/images/74f541ffee91c52b45a5aeb2d33e4ab03d339f4d.png">here</a>/the gallery. (Addons load after)</li>
<li>No connected textures? -> look at the top of the modpage!</li>
<li>"made for an older version of Minecraft" -> just load the pack as normal and it should run fine unless mojang has made significant changes to their resourcepack format</li>
<li>Make sure you have the correct version for your version and compatible base pack</li>
<li>Breaks with sodium pre 0.6.0 without indium, this is mostly because sodium (not embeddium) changes the fabric rendering system so indium fixes that</li>
</ul>

<center><h2>Why only Fusion?</h2></center>
<ul>
<li> Fusion offers many features which are required for custom connected textures, observe block surroundings, implementing specific culling, etc</li>
<li> CTM and Athena Compat did exist at the start but are Depricated; optifine/continuity do not support enough features</li>
</ul>
